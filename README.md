# Exercício — Árvore de Treinamento

Exercício do módulo de Árvore de Treinamento: treinamento supervisionado de uma árvore de decisão.

## Sobre

Treinamento de um modelo de árvore de decisão usando uma base de treinamento (`base_treinamento.csv`) e uma base de alvo/target (`target.csv`) separadas, avaliando o comportamento do modelo no cenário supervisionado.

## Tecnologias

`Python` `pandas` `scikit-learn`

## Estrutura do repositório

- `Exercicio_arvore_decisao.ipynb`
- `base_treinamento.csv`
- `target.csv`

## Como executar

Abrir o notebook em um ambiente Jupyter/Colab; as bases `base_treinamento.csv` e `target.csv` devem estar no mesmo diretório.
